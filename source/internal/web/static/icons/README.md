# Icons

`lucide.svg` contains the Lucide icons used by ExpDeck, sourced from Lucide 0.468.0:
https://github.com/lucide-icons/lucide/tree/0.468.0/icons

The Lucide ISC license is in `LICENSE.lucide`; `LICENSE.feather` preserves the MIT license for Feather-derived icons. The sprite is embedded in the Go executable and works offline.
